# Lexia

Versiones y catálogos de Lexia.

Descarga el APK desde [Releases](https://github.com/4ngelll-del/Lexia/releases). Instala sobre la versión anterior, sin desinstalar, para conservar tus datos. El APK incluye el catálogo completo.

El paquete `.lexia` es opcional y se importa en Espacio → Biblioteca viva. El ZIP contiene la base temática, listados, fuentes y documentación.

El canal automático todavía no está activado: queda pendiente adaptar y validar las redirecciones de GitHub en el cliente.
